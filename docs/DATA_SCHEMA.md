# بنية البيانات

هذا الاتفاق بين فرق البيانات (المهمتان 2 و 3) والمجسمات (4) والوكيل (6) والبيئة (1).
التعريف البرمجي الرسمي في `src/types/landmark.ts`.

## معرّفات المناطق (ثابتة)

| المعرّف | المنطقة |
|---|---|
| `najd` | نجد |
| `hijaz` | الحجاز |
| `north` | الشمال |
| `south` | الجنوب |
| `east` | الشرقية |

## معرّف المعلم (id)

- إنجليزي، حروف صغيرة، الكلمات بينها شرطة `-`.
- يبدأ باسم الموقع ثم اسم المعلم إذا لزم.
- **لا يتغير أبدًا** بعد ما يُعتمد، لأنه مربوط بالمجسم والوكيل.

أمثلة: `hegra-qasr-al-farid`، `alula-elephant-rock`، `diriyah-at-turaif`

## حقول المعلم

| الحقل | إلزامي | الوصف |
|---|---|---|
| `id` | ✅ | المعرّف الثابت |
| `regionId` | ✅ | معرّف المنطقة من الجدول فوق |
| `nameAr` | ✅ | الاسم بالعربي |
| `nameEn` | ✅ | الاسم بالإنجليزي |
| `aliases` | ✅ | أسماء ثانية يستخدمها الناس، تساعد الوكيل يفهم الزائر |
| `summaryAr` | ✅ | نبذة قصيرة (2–3 جمل) |
| `details` | | فقرات إضافية |
| `period` | | الحقبة التاريخية |
| `location` | | المدينة أو المحافظة |
| `images` | | صور من `public/images/` مع المصدر |
| `modelUrl` | | مسار المجسم، مثل `/models/landmarks/hegra-qasr-al-farid.glb` |
| `sources` | ✅ | مصدر واحد على الأقل: العنوان والرابط |
| `disclaimerAr` | | تنبيه إذا المجسم تمثيلي وليس نسخة دقيقة |

## مصادر مقبولة

هيئة التراث، وزارة الثقافة، اليونسكو، دارة الملك عبدالعزيز، الهيئة الملكية لمحافظة العلا، هيئة تطوير بوابة الدرعية، والمراجع الأكاديمية.

مثال كامل في `src/data/landmarks.sample.json`.

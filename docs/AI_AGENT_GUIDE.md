# دليل الوكيل الذكي

## كيف يتحكم الوكيل بالمتحف؟

البيئة توفر واجهة أوامر اسمها `MuseumAPI`، معرّفة في `src/types/museum-api.ts`.
الوكيل **ما يلمس المشهد مباشرة**. يستدعي هذي الأوامر فقط:

| الأمر | وش يسوي |
|---|---|
| `listRooms()` | يرجع قائمة القاعات |
| `goToRoom(roomId)` | ينقل الزائر لقاعة |
| `focusLandmark(landmarkId)` | ينقل الزائر قدام معلم |
| `openInfo(landmarkId)` | يفتح لوحة معلومات المعلم |
| `closeInfo()` | يسكّر اللوحة |
| `getVisitorState()` | وين الزائر الحين ووش المعالم القريبة |

كل أمر يرجع نتيجة:

```ts
{ ok: true,  messageAr: "تم نقلك إلى قاعة نجد" }
{ ok: false, messageAr: "لا يوجد معلم بهذا الاسم" }
```

## استرجاع المعلومات

- من ملفات `src/data/` فقط (قاعدة البيانات المشتركة).
- استخدموا حقل `aliases` عشان تفهمون الزائر لو كتب الاسم بطريقة مختلفة.
- اعرضوا `sources` مع كل إجابة.
- إذا ما فيه معلومة موثوقة، الوكيل يقول هذا بوضوح وما يألف.

## ⚠️ مفتاح API

**ممنوع منعًا باتًا** وضع مفتاح نموذج الذكاء الاصطناعي في الكود أو المستودع. المستودع عام وأي أحد يقدر ينسخه.
المفتاح يكون في خادم وسيط (Backend) أو ملف `.env` غير مرفوع.

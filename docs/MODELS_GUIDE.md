# دليل المجسمات ثلاثية الأبعاد

## الصيغة

- **`.glb` فقط** (ملف واحد فيه المجسم والخامات).
- مضغوط بـ **Draco** أو **Meshopt**.

## اسم الملف

**نفس معرّف المعلم بالضبط** من ملف البيانات:

```
public/models/landmarks/hegra-qasr-al-farid.glb
```

## حدود الأداء (مهمة جدًا للـ VR)

النظارة تحتاج 72 إطار في الثانية على الأقل. أي مجسم ثقيل يخلي التجربة تتقطع ويدوخ الزائر.

| البند | الحد |
|---|---|
| حجم الملف | أقل من 5 ميغابايت |
| عدد المضلعات | حوالي 50 ألف |
| حجم الخامة | 2048×2048 كحد أقصى |
| عدد الخامات | 1–3 لكل مجسم |

## الاتجاه والحجم

- الوحدة: **متر**.
- الأرض عند `Y = 0`، والمجسم واقف عليها.
- الواجهة الأمامية باتجاه **`+Z`**.
- المجسم في مركز `(0, 0, 0)`.

## أدوات مفيدة

- **Blender** لتعديل المجسم وتصديره.
- **gltf.report** لفحص الحجم والضغط مباشرة في المتصفح.

## مع كل مجسم سجّلي

- مصدر المجسم ورخصته.
- هل هو تمثيلي أو دقيق؟ (ينكتب في `disclaimerAr` بملف البيانات).

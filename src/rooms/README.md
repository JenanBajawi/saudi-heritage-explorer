# القاعات

**المسؤول:** المهمة 1، والمهمة 5 لغرفة الأزياء

كل قاعة في مجلد مستقل، وتعرّف نفسها بالواجهة `RoomModule`.

| المجلد | القاعة |
|---|---|
| `najd/` | نجد |
| `hijaz/` | الحجاز |
| `north/` | الشمال |
| `south/` | الجنوب |
| `east/` | الشرقية |
| `fashion/` | غرفة الأزياء |

إضافة قاعة **ما تحتاج تعديل البهو أو التنقل**.

# غرفة الأزياء

**المسؤول:** المهمة 5

تصميم غرفة الأزياء ومحتواها التفاعلي.

- المعرّف: `fashion`
- الغرفة تعرّف نفسها بالواجهة `RoomModule` من `src/types/room.ts`، مثل باقي القاعات.
- مجسمات الأزياء في `public/models/fashion/`، والصور في `public/images/fashion/`.
- بيانات الأزياء (الاسم، المنطقة، الوصف، المصادر) في `src/data/` بالتنسيق مع فرق البيانات.
- اشتغلي على فرع يبدأ بـ `fashion/`.

# الاتفاقيات المشتركة

**المسؤول:** المهمة 1. أي تعديل يحتاج موافقة مسؤولة الدمج

هنا «العقود» اللي تربط شغل كل الفرق ببعض:

| الملف | وش يعرّف |
|---|---|
| `region.ts` | معرّفات المناطق والقاعات |
| `landmark.ts` | شكل بيانات المعلم |
| `room.ts` | كيف تعرّف القاعة نفسها وأماكن المعالم فيها |
| `museum-api.ts` | أوامر المتحف للوكيل الذكي |

⚠️ **تغيير أي ملف هنا يأثر على الفريق كله.** لا تعدّلين بدون ما تتفقين مع مسؤولة الدمج.
